Current Project

TIMETAG

Time Tag is a chaotic 3D multiplayer bomb-pass game built in Unity. Players are thrust into a shared arena where a virtual bomb is passed between them — the last one holding it when the timer runs out dies. It blends competitive tension with fast, arcade-style movement. The project was developed using AI-assisted prototyping (vibe coding) with GitHub Copilot and ChatGPT to accelerate development.
